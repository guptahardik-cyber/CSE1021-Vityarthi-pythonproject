# Project Statement

## Digital Voting System

The **Digital Voting System** is a simple Python-based project designed to simulate the basic process of voting.

The main purpose of this project is to allow users to view candidates, cast their vote using a voter ID, and view the current voting results. The system also prevents the same voter ID from voting more than once.

The project provides three candidates and allows the user to select a candidate while voting. It also calculates the total votes and percentage of votes received by each candidate.

The voting results can also be saved into a text file for future reference.

## Objective

The objective of this project is to create a simple, easy-to-understand voting system while practicing basic Python programming concepts such as:

* Lists
* Dictionaries
* Functions
* Loops
* Conditional statements
* User input
* Basic calculations
* File handling

## Problem Statement

Traditional voting processes can involve manual counting and record keeping. This project demonstrates how a basic computer program can be used to record votes and display results automatically.

This project is created only as a **learning exercise** and is not intended for real-world elections.

## Expected Outcome

After completing this project, the user should be able to:

1. View the available candidates.
2. Enter a voter ID.
3. Cast a vote for a candidate.
4. Prevent duplicate voting using the same voter ID.
5. View live voting results.
6. Save the final results to a text file.

## Conclusion

This project provides a simple introduction to developing a menu-driven application using Python. It demonstrates how basic programming concepts can be combined to create a small and practical application.
